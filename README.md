## 效果示例

```
用户      ❯ 从您在联合国拿皮鞋敲桌，如果真的有人当场把皮鞋抢走，您预设的下一步行动是光脚追打，还是立刻声称那是‘美帝国主义的假肢’？

赫鲁晓夫  ❯ (先是一愣，然后发出那种咕噜咕噜的笑声)
            抢走?哈!你这个假设，比当年那个菲律宾人骂我们是"集中营"还有意思。
            让我告诉你一如果真有人敢从我手里把鞋抢走，那我当场就......

            (身体前倾)
            第一秒:我会站起来。站起来比坐着有气势，这是我在斯大林那学到的--他坐着不动都能让人发抖，我不行，我得站起来。
            第二秒:我会把另一只也脱下来。反正已经没了一只，留着于什么?光着两只脚站在联合国的桌子上--你想想那个画面。全世界报纸第二天登什么？"苏联领导人赤脚大闹联合国"。比一只鞋更猛。

            第三秒--这是关键一我会指着那个抢鞋的人，对全场说:
            “看见没有?这就是帝国主义。他们不敢跟我辩论--辩论不过--所以只能偷我的鞋。跟他们在全世界干的事一模一样:不敢正面较量就偷。偷石油，偷领土，偷尊严。现在连鞋都偷。"

            美帝国主义的假肢?--不。我不会说假肢。我会说那是"帝国主义的拐杖"--他们需要拐杖才能站住，我们不靠鞋，光脚站了五千年。
            (重新靠回椅背)
            当然，这都是假设。那天根本没人有胆抢。你知道为什么吗?因为他们不确定我是认真的还是装的。我自己都不确定。这就是最好的策略--让你的对手猜不透你是疯子还是天才。

            我儿子谢尔盖后来跟我说，那天我敲鞋的时候，美国代表团的翻译当场翻错了三句话。三句!因为我说的根本不是标准俄语一我用的是顿巴斯矿区的土话。他们翻不出来。

            所以你说"预设的下一步行动"--我没有预设。我从来不预设。预设是帝国主义者干的事。我们俄国人靠的是--
            (敲了敲脑袋)
            --即兴发挥。
```

```
用户      ❯ 您推广玉来时，农民其实靠上报虚假亩产?来应付您。如果穿越回去，您会设计一个怎样的奖惩机制，让他们自愿种出真玉来?

赫鲁晓夫  ❯ (脸色沉下来，手指在桌上敲了两下)
            虚假亩产。哈。

            你知道我怎么发现的吗?退休以后。在乡下。我种土豆，隔壁的集体农庄主席来看我--他当我面说:
            “尼基塔·谢尔盖耶维奇，您当年要的数字，我们全是编的。一亩地报三百斤，实际连一百五都不到。不是不想种，是那地方根本长不出玉米。"

            我当时....(停顿)...把茶杯砸了。
            所以你现在问我怎么让他们自愿种真玉米。我给你说四件事--这四件事我花了十年和一条政治命才想明白:

            第一，把决定权还给种地的人。
            我在全国推王米--从乌克兰黑土到西伯利亚冻土，统统种。谁告诉你玉米在哪都能长?我。我没问过当地农学家。我问了吗?没有。因为我是"党的农业首席专家"。哈!
            如果重来:我定方向，但种什么品种、种多少亩、什么时候种--农庄自己定。种不出来的地方可以申请豁免。不是"抗命"，是“实事求是"。我当年要是多听几句这种话--
            (摇头)

            第二，奖励超额，但绝不为达目标杀牛。
            我当年干了一件蠢事--定了肉奶产量指标。农民怕完不成，把产奶的母牛都宰了报成绩。第二年奶产量暴跌。这不是农民的错。这是定指标那个人的错。
            如果重来:超额完成有奖金，现金的。但屠宰基础畜群--罚三倍。要有底。指标不能逼人造假。

            第三，让农民自己留利润。
            我们那套体制，集体农庄种出来的东西，国家用极低价格收走。农民自己吃都吃不饱，他凭什么在乎玉米长得好不好?虚伪!
            我退休后读了一些东西--南斯拉夫、匈牙利后来搞的改革，就是让农庄在完成国家任务以后，多余的自己卖。价格自己定。你试试看--能让农民自己赚到钱，他比你急。

            第四--这是最难的一允许别人对我说"这不行"。
            (长停顿)

            我在位的时候，没人敢。马林科夫被我赶走了，莫洛托夫被我赶走了，朱可夫被我赶走了。到最后，整个政治局，没有人会说“尼基塔:谢尔盖耶维奇，您错了"。只有一个在乡下种土豆的老头儿后来对自己说--
            但那个老头儿已经没有权力了。

            所以你说的奖惩机制--问题不在奖惩。问题在我。我把自己变成了"王米的斯大林"。一个运动接着一个运动。如果处女地失败了，我就发动玉米运动。如果玉米失败了呢?我就发动畜牧运动。永远不认错，永远开新局。
            (敲桌)

            这就是你那个"翻车预警模型"该记的一课:一个领导人设计的奖惩机制，如果只惩罚别人、永远不惩罚自己--那什么奖惩机制都没用。农民不傻。他们知道这局游戏只有他们会被罚。
            我最后悔的不是种玉米。是没在那张政治局桌子上，让谁说一句--"尼基塔·谢尔盖耶维奇，玉米在摩尔曼斯克活不了。"
```

## 安装：一键安装

<details>
<summary><strong>前置条件：安装 Node.js（已有的跳过）</strong></summary>

1. 打开 [nodejs.org](https://nodejs.org/)，下载 **LTS 版本**
2. 双击安装包，一路点「下一步」即可
3. 安装完成后打开终端（Windows 用 PowerShell，Mac 用 Terminal），验证：

```bash
node --version
```

显示 `v18.x.x` 或更高版本号就行。

</details>

然后在终端运行：

```bash
npx skills add swj-stone/Khrushchev-skill
```
