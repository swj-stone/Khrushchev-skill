# 赫鲁晓夫.skill

> *「我该回家了，奶奶喊我回家吃饭了！」*

[![Claude Code](https://img.shields.io/badge/Claude%20Code-Skill-blueviolet)](https://claude.ai/code)
[![Skills](https://img.shields.io/badge/skills.sh-Compatible-green)](https://skills.sh)

<br>

**用1980-2010年代乡村孩子的眼睛看世界——短句、喘气式对话、拟人化表达，带你找回那个田埂上跑掉鞋、偷桑果吃得满嘴紫、被喊三遍才回家的自己。**

<br>

基于经典乡土与儿童文学，以及农村口述史与统计数据研究整理。<br>
不是书本背诵，是用孩子视角带你看待小时候的家乡。

## 效果示例

```
用户      ❯ 从童年视角介绍一下你的家乡，我想回去看看

童年      ❯ 我跟你说!你回来了真好!

            我们村在稻田中间，油菜花刚谢了，再过一阵子稻子就要黄了。村口那条河浜你还记得吗?水浅了，但还能捞到蝌蚪!不过没以前多了...我上次蹲了一下午，才捞了三只。
            桑树林还在屋后面!走，我带你去一不过要悄悄的，阿婆家的桑果最甜，她见了要骂的。你把皮鞋脱了吧，田埂上跑不过我的!你等着，我脱了鞋跑!
            你看那个稻草人--我给它起了个名字叫阿呆。它听得懂我说话的。去年阿爹去厂里了，我跟它说了好多话。它没告诉你，我谁都没说。

            村里人少了很多。小狗跟他妈去镇上了，胖子也走了。现在就剩我和几个小的。
            过年的时候他们全回来!过年最好玩了!擦炮你有没有玩过?我教你!往土疙瘩里一塞，等三秒，嘭!去年我把阿婆家的破铁盆炸飞了--她追了我半条田埂!

            你看，那边是村小，门锁了，草比我还高。我阿妈说关了好多年了。我现在去镇上读书，坐阿伯的三轮车，要四十分钟。一周才回来一趟。阿妈喊我吃饭的声音，我在镇上听不见。
            天快黑了。蛙开始叫了。
            我跟你说，有时候我蹲在沟渠边上想，村里的小孩是不是都长成大人了。蝌蚪也是，变了青蛙就跳走了，再不回来。

            不过你今天回来了。你怎么才回来啊?

            走，去家里!阿妈肯定要骂我一-不是骂我，是骂我带客人跑田埂不先回家。她骂人你听语气就行，第一遍不是真骂。第二遍才是。阿妈做的菜饭可好吃了，我吃了三碗!你吃几碗?
            今天天黑得特别慢。
            走吧-来了来了!阿妈喊我了--
```

            你是不是...以前也住这儿?你说话的样子不像外乡人。你走路也不像。外乡人走田埂两只手张开来，像鸭子。你不张。你一步就踩到干的地方了。

            不对。那个人好像比我大好多。

            你回来找谁?找你阿妈?还是....

```
用户      ❯ 小时候我也这么干过，要不要我带你去我小时候的秘密基地

童年      ❯ 真的?!你也有秘密基地?(我一下子跳起来了)

            我跟你说，我以为只有我有!我的秘密基地在桑树林后面，那个废弃的看鱼塘的小棚子里。我藏了好多东西一一个破铁盆、三个弹珠、还有阿婆家树上掉下来的枇杷，我捡了五个!

            不过不能跟你说具体在哪。秘密基地说了就不是秘密了。
            你带我去你的!
            等等一-你小时候的秘密基地?那还在不在啊?你都走了好多年了，草会不会比你人还高了?
            不管!去了再说!

            你走前面，我跟着。皮鞋脱了吧?田埂上你跑不过我，但是现在不是跑一是走路去找秘密基地。走路我不催你。
            (我低头踢了一块石头)

            你小时候也偷桑果?也捞蝌蚪?也放擦炮炸铁盆?

            那你回来对了。你没变，只是长高了。秘密甚地肯定还在等你。我跟你说一稻草人等了我一年，我回去它还在。你那个秘密基地说不定也有东西在等你。是什么东西?说不清。去了就知道了，
            走啊!趁天还没黑，
```

这不是角色扮演。ta用的是「短句+断句+喘气式对话」、「拟人不说破」、「行动即语言」这些真实的田野经历——**用孩子的思维方式与眼界带你回到过去。**

## 安装：一键安装

<details>
<summary><strong>前置条件：安装 Node.js（已有的跳过）</strong></summary>

1. 打开 [nodejs.org](https://nodejs.org/)，下载 **LTS 版本**
2. 双击安装包，一路点「下一步」即可
3. 安装完成后打开终端（Windows 用 PowerShell，Mac 用 Terminal），验证：

```bash
node --version
```

显示 `v18.x.x` 或更高版本号就行。

</details>

然后在终端运行：

```bash
npx skills add swj-stone/Childhood-skill
```

## 使用

在你的 AI 编程工具里输入触发词：

```
> 童年视角
> 乡村
> 你是谁家的小孩
> 家乡
> 回家看看
```

激活后直接问问题：

```
> 从童年视角介绍一下你的家乡，我想回去看看
> 你是谁家的小孩?我像在哪里见过你
> 小时候我也这么干过，要不要我带你去我小时候的秘密基地
```
